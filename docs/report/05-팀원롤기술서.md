# 팀원 롤 기술서

**팀명** MEGA · **구성** 3인 · **팀대표자** 조재영
**작품** `Let's go!!` — 10개 스테이지를 걷고 뛰어 깃발까지 도달하는 2D 액션 플랫포머
**저장소** https://github.com/dm-rooney-lee/mega1

## 1. 팀원별 역할 및 담당 영역

### 조재영 — 팀 리드 · 개발 총괄

**담당 역할**
팀 전체 일정과 진척 관리, 작업 분배와 우선순위 조정, 개발 방향 결정, 팀 개발 표준 수립

**담당 영역**
- **팀 운영** — 전체 일정과 범위 관리, 팀원별 역할 배분, 산출물 취합
- **게임 시스템 개발** — 적·장애물 등 게임플레이 요소 설계 및 구현, 후반부 스테이지 콘텐츠
- **아트 방향 및 그래픽** — 세계관 설계, 캐릭터·지형 그래픽, 화면 일러스트
- **사운드** — 효과음 연출 및 배경음악 믹스 설계
- **개발 표준 수립** — AI 협업 규칙 문서화, 자동 검증 체계 도입

---

### 이동민 — 게임 구조 설계 · 개발

**담당 역할**
프로젝트 초기 셋업과 프로토타입 제작, 게임 전체 구조 설계, 저장소 운영

**담당 영역**
- **프로젝트 셋업** — 기술 스택 선정 및 개발 환경 구축, 플레이 가능한 프로토타입 제작
- **게임 구조 설계** — 화면 전환 구조, 스테이지 진행 및 재시작 흐름
- **스테이지 콘텐츠 개발** — 중반부 스테이지 설계 및 구현
- **개발 편의 기능** — 특정 스테이지·지점부터 바로 시작하는 디버그 기능으로 팀 전체의 테스트 시간 단축
- **저장소 운영** — 브랜치 전략 수립, 코드 리뷰 및 머지 관리

---

### 강재혁 — 게임 기획 · 개발

**담당 역할**
시장 리서치를 통한 게임 방향성 수립, 콘텐츠 기획, 레벨 디자인 및 개발

**담당 영역**
- **시장 리서치** — 최근 주목받는 인디게임을 조사·분석하고, 이를 바탕으로 게임의 방향성과 핵심 재미 요소를 정의
- **콘텐츠 명세 작성** — 신규 콘텐츠 10종(점프대·이동 발판·진자·팝업 가시·발사체 적 등)의 동작 규칙과 파라미터를 구현 착수 전 명세로 확정
- **레벨 디자인** — 난이도 곡선 설계 및 초반 스테이지 구성
- **게임플레이 요소 개발** — 명세한 콘텐츠를 적·장애물로 직접 구현
- **수치 관리 구조 정리** — 이동 속도·점프·공격 주기 등 게임 수치를 한곳에 모아 관리하도록 정리

## 2. 협업·분업 방식

- **역할 분담** — 팀 운영·개발 총괄(조재영) · 게임 구조(이동민) · 기획/리서치(강재혁) 세 축으로 나누고, 3인 모두 자신의 영역에서 개발을 병행했습니다.
- **영역 분리** — 기획·레벨 / 게임 시스템·연출 / 화면 흐름으로 담당 영역을 나눠 작업 충돌을 최소화했습니다.
- **개발 프로세스** — GitHub 기능 브랜치 → Pull Request → 코드 리뷰 → 머지 절차를 따랐습니다.
- **품질 기준** — 자동 테스트와 타입 검사 통과를 머지 조건으로 운영했고, 장애물 배치는 계산 기반 자동 검증으로 전 스테이지를 검사했습니다.
- **AI 협업** — 3인 모두 Claude Code를 주력으로 사용했습니다. 프로젝트 규칙 문서로 AI가 지켜야 할 기준을 명문화해 산출물의 일관성을 확보했고, 생성된 코드는 담당자가 직접 리뷰한 뒤 머지했습니다.
- **의사결정** — 영역별 기술 선택은 담당자가, 게임 방향은 3인 합의로 결정하며, 합의가 나지 않으면 팀대표자가 결정합니다.
