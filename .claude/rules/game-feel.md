# 플레이어 감각을 바꿀 때의 관례

소리·조작감·난이도·화면 연출처럼 **플레이어가 보고 듣고 느끼는 것**을 바꾸는 작업에 적용한다. 판단 절차는 `CLAUDE.md`의 "플레이어가 느끼는 것을 바꾸는 요청"에 있고, 이 문서는 그때 참고할 구체 관례를 담는다.

## 요청이 관례에서 벗어났는지 알아보는 법

아래 중 하나라도 해당하면 구현 전에 관례를 먼저 말한다.

| 신호 | 예 |
|---|---|
| 요청이 어떤 요소를 **없애는** 방향이다 | "플레이 중 음악을 없애자", "화면 흔들림을 빼자" |
| 상용 게임에서 그렇게 하는 걸 본 적이 없다 | 플레이 중 완전 무음인 플랫포머는 드물다 |
| 요청이 증상이 아니라 **해결책 모양**이다 | "효과음이 안 들려"(증상) vs "음악을 끄자"(해결책) |
| 수치 하나를 극단으로 미는 요청이다 | "0으로 만들자", "두 배로 하자" |

**"명확한 요청"은 면제 사유가 아니다.** 오히려 명확할수록 그대로 구현하기 쉬워서 위험하다.

## 오디오 믹스 (검증됨)

**음악과 효과음이 같은 음량이면 서로 잡아먹는다.** 음악을 배경으로 낮게 깔아야 효과음이 위로 튀어나온다.

```
   음량
    ▲
0.4 │ ─────────  ▓▓  ▓▓ ─────────      ← 효과음 (짧고 크게, 위로 튄다)
0.2 │ ░░░░░░░░░░░░░░░░░░░░░░░░░░░      ← 배경음악 (모든 화면 공통, 뒤로 물러남)
    └──────────────────────────────▶
```

이 저장소의 현재 값 (`src/config.ts`):

| 상수 | 값 | 쓰이는 곳 |
|---|---|---|
| `BGM_VOLUME` | `0.2` | 타이틀·플레이·죽음·승리 4개 화면 전부(통일, 2026-08-09) |
| `SFX.MASTER_VOLUME` | `0.4` | 모든 효과음 |

**`BGM_VOLUME` < `SFX.MASTER_VOLUME` 관계가 깨지면 안 된다.** 이 관계가 뒤집혀 있었던 것(음악 0.5 > 효과음 0.4)이 "플레이 중에 효과음이 안 들린다"의 진짜 원인이었다.

화면마다 배경음악 볼륨을 다르게 주던 것(타이틀·죽음·승리는 크게, 플레이 중엔 작게)은 2026-08-09에 통일했다 — "게임 볼륨이 너무 크다"는 피드백의 원인이 화면 전환마다 음악이 갑자기 커지는 것이었다. 대신 사용자가 4개 화면 모두의 톱니바퀴(⚙) 버튼으로 배경음악·효과음 볼륨을 각각 직접 낮출 수 있다 — `src/settings.ts`(저장), `src/scenes/SettingsScene.ts`(UI). 100%는 이 표의 기준값이고, 그보다 크게 키우는 기능은 없다(설계: `docs/superpowers/specs/2026-08-09-bgm-volume-unify-and-settings-design.md`).

효과음이 묻힐 때 쓰는 방법을 손이 적게 가는 순서로 나열하면:

1. **볼륨 분리** — 음악을 효과음보다 확실히 낮춘다. 대부분 이걸로 해결된다.
2. **더킹** — 중요한 효과음이 날 때 음악이 잠깐 작아졌다 돌아온다.
3. **음역 분리** — 음악은 중저음, 효과음은 중고음에 배치한다. 사운드 디자이너 영역.
4. **적응형 레이어** — 상황에 따라 악기를 켜고 끈다. 이 규모의 PoC에는 과하다.

**음악을 아예 끄는 것은 연출 장치이지 믹스 해법이 아니다.** 잠입 구간, 보스 등장 직전의 정적처럼 "고요함 자체가 콘텐츠"일 때만 쓴다.

## 브라우저 제약 (검증됨)

브라우저는 진짜 사용자 입력이 있기 전에는 소리를 재생하지 않는다. **코드로 만든 가짜 입력 이벤트로는 우회할 수 없다** — 브라우저가 이벤트마다 진짜 입력인지 표시해두고 그 표시가 있는 것만 인정한다. 이 제약을 우회하는 방법을 찾지 말고, 첫 진입 무음을 수용하는 설계를 택한다.

## 내가 모르는 영역

조작감(점프 느낌, 입력 관용도), 난이도 곡선, 타격감·피드백 연출 등은 이 문서에 아직 검증된 내용이 없다.

**그 영역의 요청을 받으면 "보통은 이렇습니다"를 상상해서 쓰지 말 것.** 모른다고 말하고 조사한 뒤 답한다. 조사해서 확인한 관례는 이 문서에 절을 추가해 남긴다 — 다음 세션이 같은 조사를 반복하지 않도록.
